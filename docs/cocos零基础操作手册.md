# Cocos Creator 零基础操作手册

> 用户画像：**完全没接触过 Cocos Creator 的开发者**  
> 宗旨：**能让 AI 用代码做的，全部用代码做；必须你手动做的，给到"点哪里→看到什么→下一步"的步骤级指引**  
> 约定：**任何时候你不清楚一步该做什么，直接问 AI，不要盲点**

---

## 一、总原则：代码优先模式

本项目采用"**代码优先 UI 模式**"，意味着：

| 事情                          | 谁做          | 你动手频率            |
| ----------------------------- | ------------- | --------------------- |
| 所有 TypeScript 代码          | AI 写         | 0                     |
| UI 节点、布局、样式           | AI 用代码创建 | 0                     |
| 动效、交互、网络              | AI 写         | 0                     |
| **新建空场景**                | 你点编辑器    | **整个项目约 1-2 次** |
| **挂载入口脚本**              | 你拖一次      | **整个项目约 1 次**   |
| **导入美术资源**（图片/音效） | 你拖文件夹    | 每次有新美术时        |
| **点"预览"按钮查看效果**      | 你点一下      | 日常高频              |
| **点"发布"出包**              | 你点一下      | P4 阶段               |

**换句话说，整个项目下来，你需要在 Cocos 编辑器里的动手操作，加起来不会超过 30 分钟。**

## 二、第一次动手：安装 Cocos Creator

**目标**：让电脑上有一个能打开本项目的 Cocos Creator 3.8 LTS。

### 步骤

1. **下载 Cocos Dashboard**（账号管理器，不是编辑器本身）
   - 访问：<https://www.cocos.com/creator>
   - 点页面上的 **"免费下载"** 按钮
   - 选择 **Mac** 版本（你的系统是 darwin）
   - 下载到的文件是 `CocosDashboard-v*.dmg`

2. **安装 Dashboard**
   - 双击 `.dmg` 文件
   - 把 `CocosDashboard` 图标拖到 `Applications` 文件夹
   - 打开"启动台"搜 `CocosDashboard` 点开
   - 首次打开 Mac 可能提示"无法验证开发者"：去 **系统设置 → 隐私与安全性 → 底部点"仍要打开"**

3. **在 Dashboard 里登录**
   - 首次打开 Dashboard 会要求登录 Cocos 账号
   - 没有账号就点"注册"，邮箱注册即可（免费）

4. **下载 Cocos Creator 3.8 LTS**
   - 在 Dashboard 左侧点 **"编辑器"** 选项卡
   - 顶部筛选器选 **"LTS"** 类别
   - 找到 **3.8.x** 版本（选最新的 3.8 LTS 小版本，如 3.8.4/3.8.5）
   - 点 **"下载"** 按钮，等待完成（约 500MB-1GB，国内网络可能较慢）

5. **确认安装成功**
   - 下载完成后版本号旁会显示 **"打开"** 按钮
   - **此时先不要打开**，等下一步（我来告诉你怎么用它打开本项目）

### ✅ 完成标志

- Dashboard 里能看到 Cocos Creator 3.8 LTS，状态是 **"打开"** 可点击（不是"下载"）

### ❓ 遇到问题怎么办

直接告诉 AI 你卡在哪一步 + 截屏描述错误现象，不要自己硬猜。

## 三、第二次动手：用 Cocos Creator 打开我们的项目

**目标**：把 `packages/client` 目录变成 Cocos 能识别的项目。

### 前置说明

我们的项目目录 `packages/client` 现在**只有 TypeScript 脚本和 package.json**，没有 Cocos 的项目元数据（`settings/`、`assets/meta` 等）。需要让 Cocos 用"导入现有项目 / 新建项目"的方式识别它。

### 步骤

1. **打开 Cocos Dashboard** → 左侧 **"项目"** 选项卡
2. **点右上角 "新建项目"**（不是"导入"）
3. **在弹出的模板选择页**：
   - 左侧选 **"Empty (2D)"** 模板（空的 2D 项目）
   - 右侧填：
     - **项目名称**：`bid-king-client`
     - **项目路径**：点"浏览"，**导航到** `/Users/darrick/Documents/code/bid-king/packages/client`
     - ⚠️ **关键**：选的是 `client` 文件夹本身作为项目根目录
4. **点 "创建并打开"**
5. Cocos Dashboard 会弹窗警告 **"目录非空，确认继续吗？"**
   - 点 **"继续"**（我们希望 Cocos 在已有目录上创建项目文件）
6. 等 Cocos Creator 启动并加载项目（首次约 30 秒-1 分钟）

### ✅ 完成标志

- 你看到 Cocos Creator 主界面打开了
- 左下角 **"资源管理器"** 能看到 `assets` 文件夹，里面有 `scripts/platform/Bootstrap.ts` 和 `logger.ts`（这是我们 P0 留的文件）
- 标题栏显示 "bid-king-client"

### 🧹 完成后告诉 AI

创建完成后，**回到终端运行**这一条命令并把结果贴给 AI：

```bash
cd /Users/darrick/Documents/code/bid-king && ls packages/client
```

AI 会根据输出判断 Cocos 生成了哪些新文件，然后指导你：

- 哪些文件需要 `git add`
- 哪些文件需要加进 `.gitignore`
- 是否需要调整 `tsconfig.json`

### ❓ 遇到问题怎么办

- 如果导入后 `Bootstrap.ts` 报红：**别改**，截屏告诉 AI，通常是 TS 配置冲突，AI 会帮你修。
- 如果 Cocos 把 `package.json` 覆盖了：**别存盘**，立即告诉 AI。

## 四、第三次动手：创建入口场景（后续 P1 开始时做）

> 这一步 **现在不用做**，等 P1 开始时 AI 会告诉你做。

**目标**：有一个名字叫 `Main.scene` 的空场景作为游戏入口。

### 届时的步骤（预告）

1. 资源管理器 → `assets` 文件夹 → 右键 → "新建" → "场景"
2. 命名为 `Main`
3. 双击 `Main.scene` 打开
4. 场景里只会有一个 `Canvas` 节点（自动生成）
5. 右键 `Canvas` → "创建" → "空节点"，命名为 `Root`
6. 拖 `Bootstrap.ts`（或后续 AI 指定的脚本）到 `Root` 节点上
7. 按 `Cmd+S` 保存场景
8. 点编辑器顶部中间的 **▶️ 预览** 按钮，查看效果

**剩下的所有 UI 你都不用在编辑器里建——AI 会在代码里用 `new Node()` 方式创建，你只需要点"预览"看效果。**

## 五、日常高频操作：预览 / 刷新

### 预览项目（每次想看效果时）

1. 顶部工具栏找到 **▶️ 浏览器预览** 按钮
2. 点一下，浏览器会自动打开 `http://localhost:7456`
3. 控制台（浏览器 F12）能看到日志输出

### 让 Cocos 识别新代码

AI 写完新的 `.ts` 文件后：

- **一般情况**：Cocos 会自动检测到文件变化并重新编译（底部会有小圈圈转）
- **偶尔不生效时**：顶部菜单 **开发者 → 重新编译脚本**

### 让 Cocos 识别新资源

当你把图片/音效拖进 `assets/` 目录后：

- Cocos 会自动生成 `.meta` 文件
- **这些 `.meta` 文件必须 `git add` 入库**，否则团队其他人会看到"资源丢失"

## 六、美术资源导入（P3 阶段开始做）

> 现在不用做，P3 阶段再按这里操作。

1. 把图片文件（`.png`/`.jpg`）直接拖进 Cocos 编辑器的 **资源管理器** → `assets/resources/` 文件夹
2. Cocos 自动生成 `.meta` 同名文件
3. 在 **属性检查器** 里看图片的：
   - **Type**：如果是要切 9 宫格的 UI 框，设为 `sliced`
   - **PixelsPerUnit**：UI 项目保持默认
4. 导入完成告诉 AI 图片文件名，AI 会在代码里用 `resources.load('xxx', SpriteFrame, ...)` 加载

## 七、最常见 5 个新手疑问

### Q1：我什么都不会，会不会拖慢进度？

**不会。** 代码优先模式下，你只负责"点预览看效果"+"提交代码"。遇到问题截屏问 AI 就行。

### Q2：Cocos Creator 里看到红色报错怎么办？

**不要乱点**。复制报错文本或截屏给 AI，AI 大概率能远程诊断。

### Q3：场景文件（`.scene`）要入库吗？

**要**。虽然它是 JSON，但是是 Cocos 管理的数据。用 Git 提交时会跟其他文件一起 commit。

### Q4：哪些文件不能入库？

已经在 `.gitignore` 里排除了：

- `library/`（缓存）
- `temp/`（临时）
- `local/`（个人设置）
- `profiles/`（个人配置）
- `build/`（构建产物）

### Q5：AI 写的代码怎么在 Cocos 里运行？

**AI 写完 → 你切回 Cocos 编辑器 → 等底部"脚本编译完成" → 点预览 ▶️**，就这样。
