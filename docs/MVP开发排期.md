# 《竞拍之王》手游复刻 - MVP 开发排期与任务拆解

> 制定时间：2026 年 4 月  
> 团队规模：1-2 人（前端背景，按 1.5 人有效工时折算）  
> 技术栈：Cocos Creator 3.x + Colyseus(Node.js/TS) + MongoDB + Redis  
> 目标平台：iOS + Android + 微信小游戏  
> MVP 定义：4 人真实联机、完整一局闭环（暗标 + 开箱 + 结算 + 藏品入库）、干员技能 3 个、经济系统基础闭环、可内测分享

---

## 一、总览

| 阶段                | 周期                     | 里程碑            | 关键产出                           |
| ------------------- | ------------------------ | ----------------- | ---------------------------------- |
| **P0 工程准备**     | 1 周                     | 仓库/协议/CI 就绪 | Monorepo、协议包、基础脚手架       |
| **P1 核心循环原型** | 2 周                     | 单机可跑一局      | 暗标主循环（无联机）               |
| **P2 联机 MVP**     | 3 周                     | 4 人真实联机成功  | Colyseus 接入、房间匹配、状态同步  |
| **P3 系统完整化**   | 4 周                     | 正式版功能齐全    | 干员技能、经济系统、账号、藏品图鉴 |
| **P4 三端适配**     | 2 周                     | 三端跑通          | 小游戏分包、iOS/Android 打包       |
| **P5 打磨 & 上线**  | 2 周                     | 可内测上线        | 防作弊、监控、压测、灰度           |
| **合计**            | **14 周（约 3.5 个月）** | 首个可内测版本    | —                                  |

**排期策略**：每周按 5 工作日估算，每日有效产出按 6h 计（扣除沟通/调试/返工）。1-2 人团队会在 P2/P3 出现瓶颈，建议此阶段适当拉长。

**P1 验收标准（DoD）**：

- ✅ 单机点击"开始游戏"，能完整走完一局。
- ✅ 开箱演出达到"让人想再玩一局"的基础爽感（截屏/录屏展示）。

**P2 验收标准（DoD）**：
